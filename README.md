# Real-Time Face Detector with Python & OpenCV

An AI-powered computer vision application that detects human faces in real-time using a live webcam stream. Built with Python and OpenCV's Haar Cascade classifier.

## Features
- Real-time face detection from a continuous webcam stream.
- Dynamic bounding box overlay around detected faces.
- Status label rendering above detected bounding boxes.
- Frame resizing for optimized real-time processing.

## Prerequisites
- Python 3.8+
- Webcam hardware
